4. CRIANDO NOVO AGENTE
================================================================================

Listar templates:
  python scripts/create_agent.py --list

Criar agente do template:
  python scripts/create_agent.py --name agent_001 --template walker --world walker-training.wbt --description "Bípede terreno acidentado"

Templates disponíveis:
  - walker    : Locomoção bípede/quadrúpede (12 DOF, LiDAR, IMU)
  - arm       : Manipulação braço robótico (6 DOF, rastreamento efetuador)
  - drone     : Controle quadricóptero (4 motores, posição/velocidade)
  - default   : Template genérico

Isso cria:
  agents/agent_001/
  ├── config.yaml          # Config agente (EDITE ESTE)
  ├── train.py             # Entry point treinamento
  ├── eval.py              # Entry point avaliação
  ├── model/__init__.py    # Arquiteturas customizadas (opcional)
  ├── logs/                # Logs treinamento (auto-criado)
  ├── checkpoints/         # Checkpoints modelo (auto-criado)
  └── videos/              # Vídeos avaliação (auto-criado)

================================================================================
5. CONFIGURANDO SEU AGENTE
================================================================================

Edite agents/agent_001/config.yaml:

Seções principais para customizar:

  env:
    world: "training.wbt"           # Arquivo mundo Webots
    observation_keys: [...]         # Nomes sensores (devem match Webots)
    action_keys: [...]              # Nomes atuadores (devem match Webots)
    reward_weights:                 # PESOS FUNÇÃO RECOMPENSA
      forward_vel: 1.0
      energy: -0.01
      alive: 0.1
      stability: 0.5

  ppo:                              # Hiperparâmetros PPO
    learning_rate: 3e-4
    n_steps: 2048
    batch_size: 64
    n_epochs: 10
    gamma: 0.99
    clip_range: 0.2
    ent_coef: 0.01

  neural:                           # Arquitetura rede
    actor:
      hidden_sizes: [256, 256]
      activation: "tanh"
    critic:
      hidden_sizes: [256, 256]

  training:
    total_timesteps: 5000000
    eval_freq: 50000
    n_eval_episodes: 10

FUNÇÃO RECOMPENSA CUSTOM:
Edite agents/agent_001/train.py, modifique custom_reward_fn():
  def custom_reward_fn(obs, action, next_obs, info):
      reward = 0.0
      breakdown = {}
      # Sua lógica recompensa aqui
      return reward, breakdown

================================================================================
6. SETUP MUNDO WEBOTS
================================================================================

1. Abra Webots, crie novo mundo em webots/worlds/seu_mundo.wbt
2. Adicione robô com DEF name "PPO_ROBOT"
3. Adicione sensores: Lidar, InertialUnit, Gyro, Accelerometer, GPS, PositionSensors
4. Adicione atuadores: Motors com controle posição
5. Adicione Supervisor para controle ambiente
6. Defina controller robô = "ppo_agent"
7. Defina controller supervisor = "supervisor"

PROTO robô em webots/proto/robots/SeuRobo.proto:
  PROTO SeuRobo [ ... ] {
    Robot {
      name "PPO_ROBOT"
      controller "ppo_agent"
      children [ ... sensores e atuadores ... ]
    }
  }

================================================================================
7. TREINAMENTO
================================================================================

Navegue ao diretório agente:
  cd agents/agent_001

Validação rápida (1 episódio, sem salvar):
  python train.py --dry-run --verbose

Treino completo:
  python train.py

Retomar checkpoint:
  python train.py --resume checkpoints/latest.pt

Override config via CLI:
  python train.py --override ppo.learning_rate=1e-4 training.total_timesteps=1000000

Com Weights & Biases:
  python train.py --wandb --wandb-project meu-projeto

Monitorar (terminal separado):
  tensorboard --logdir logs/tensorboard

Comparar múltiplos:
  python scripts/evaluate.py --agents agent_001,agent_002,agent_003 --compare --output comparacao.json

Renderizar avaliação:
