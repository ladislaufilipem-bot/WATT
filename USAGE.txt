4. CREATING A NEW AGENT
================================================================================

List available templates:
  python scripts/create_agent.py --list

Create agent from template:
  python scripts/create_agent.py --name agent_001 --template walker --world walker-training.wbt --description "Bipedal walker on rough terrain"

Available templates:
  - walker    : Bipedal/quadruped locomotion (12 DOF, LiDAR, IMU)
  - arm       : Robotic arm manipulation (6 DOF, end-effector tracking)
  - drone     : Quadcopter control (4 motors, position/velocity)
  - default   : Generic template

This creates:
  agents/agent_001/
  ├── config.yaml          # Agent configuration (EDIT THIS)
  ├── train.py             # Training entry point
  ├── eval.py              # Evaluation entry point
  ├── model/__init__.py    # Custom architectures (optional)
  ├── logs/                # Training logs (auto-created)
  ├── checkpoints/         # Model checkpoints (auto-created)
  └── videos/              # Evaluation videos (auto-created)

================================================================================
5. CONFIGURING YOUR AGENT
================================================================================

Edit agents/agent_001/config.yaml:

Key sections to customize:

  env:
    world: "training.wbt"           # Webots world file
    observation_keys: [...]         # Sensor names (must match Webots)
    action_keys: [...]              # Actuator names (must match Webots)
    reward_weights:                 # REWARD FUNCTION WEIGHTS
      forward_vel: 1.0
      energy: -0.01
      alive: 0.1
      stability: 0.5

  ppo:                              # PPO hyperparameters
    learning_rate: 3e-4
    n_steps: 2048
    batch_size: 64
    n_epochs: 10
    gamma: 0.99
    clip_range: 0.2
    ent_coef: 0.01

  neural:                           # Network architecture
    actor:
      hidden_sizes: [256, 256]
      activation: "tanh"
    critic:
      hidden_sizes: [256, 256]

  training:
    total_timesteps: 5000000
    eval_freq: 50000
    n_eval_episodes: 10

CUSTOM REWARD FUNCTION:
Edit agents/agent_001/train.py, modify custom_reward_fn():
  def custom_reward_fn(obs, action, next_obs, info):
      reward = 0.0
      breakdown = {}
      # Your reward logic here
      return reward, breakdown

================================================================================
6. WEBOTS WORLD SETUP
================================================================================

1. Open Webots, create new world in webots/worlds/your_world.wbt
2. Add robot with DEF name "PPO_ROBOT"
3. Add sensors: Lidar, InertialUnit, Gyro, Accelerometer, GPS, PositionSensors
4. Add actuators: Motors with position control
5. Add Supervisor for environment control
6. Set robot controller to "ppo_agent"
7. Set supervisor controller to "supervisor"

Robot PROTO example in webots/proto/robots/YourRobot.proto:
  PROTO YourRobot [ ... ] {
    Robot {
      name "PPO_ROBOT"
      controller "ppo_agent"
      children [ ... sensors and actuators ... ]
    }
  }

================================================================================
7. TRAINING
================================================================================

Navigate to agent directory:
  cd agents/agent_001

Quick validation (1 episode, no saving):
  python train.py --dry-run --verbose

Full training:
  python train.py

Resume from checkpoint:
  python train.py --resume checkpoints/latest.pt

Override config via CLI:
  python train.py --override ppo.learning_rate=1e-4 training.total_timesteps=1000000

With Weights & Biases logging:
  python train.py --wandb --wandb-project my-project

Monitor training (separate terminal):
  tensorboard --logdir logs/tensorboard

13. DEVELOPMENT RULES (MANDATORY)
================================================================================

READ init/rules.md BEFORE MAKING CHANGES

Key Principles:
1. EFFICIENCY: Reuse core/, configs over hardcoded values, batch operations
2. ORGANIZATION: 1 agent = 1 folder, shared code ONLY in core/
3. MODULARITY: Single responsibility per module
4. REPRODUCIBILITY: Versioned configs, seeded randomness, checkpointing
5. OBSERVABILITY: Structured JSONL logging, TensorBoard, metrics

PROHIBITED:
- import agents.agent_XXX in core/ (coupling)
- Hardcoded paths (use config)
- Global variables (use dependency injection)
- print() for logging (use logging + JSONL)
- Magic numbers (use YAML config)
- Direct Webots API in agents (use core.env.WebotsWrapper)

================================================================================
15. COMMON ISSUES & SOLUTIONS
================================================================================

Webots not found:
  - Set WEBOTS_HOME environment variable
  - Verify webots executable exists at $WEBOTS_HOME/webots

Import errors:
  - Run from project root: cd C:\Users\ladis\OneDrive\Desktop\ia
  - Ensure PYTHONPATH includes project root

CUDA out of memory:
  - Reduce batch_size in config
  - Reduce n_steps (rollout length)
  - Enable gradient checkpointing

Training divergence:
  - Reduce learning_rate by 10x
  - Enable reward normalization
  - Check observation normalization

Webots crashes:
  - Check webots/controllers/ppo_agent/controller.log
  - Reduce physics timestep in world file
  - Add sensor noise filtering in wrapper
